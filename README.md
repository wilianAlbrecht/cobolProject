# cobolProjects



Projetos Básicos.


Calculadora Simples:
Crie um programa que permita ao usuário realizar operações matemáticas básicas (adição, subtração, multiplicação e divisão).

Gerenciador de Contatos:
Desenvolva um sistema simples para armazenar, listar, editar e excluir contatos. Utilize arquivos para armazenar os dados.

Conversor de Moedas:
Implemente um programa que converta valores entre diferentes moedas, utilizando taxas de câmbio fixas.

Jogo da Adivinhação:
Crie um jogo onde o usuário deve adivinhar um número gerado aleatoriamente pelo programa.



Projetos Intermediários



Sistema de Controle de Estoque:
Desenvolva um sistema que permita gerenciar produtos em estoque, incluindo funcionalidades para adicionar, remover e listar produtos.

Sistema de Vendas:
Crie um sistema que simule um ponto de venda, onde o usuário pode registrar vendas, calcular totais e gerar relatórios.

Agenda de Compromissos:
Implemente um programa que permita ao usuário agendar compromissos, visualizar compromissos futuros e editar ou excluir compromissos existentes.

Simulador de Empréstimos:
Desenvolva um sistema que calcule parcelas de empréstimos com base em diferentes taxas de juros e prazos.





Projetos Avançados





Sistema de Gestão de Funcionários:
Crie um sistema completo para gerenciar informações de funcionários, incluindo cadastro, atualização de dados, cálculo de salários e geração de relatórios.

Sistema de Reservas de Hotel:
Desenvolva um sistema que permita gerenciar reservas de quartos, incluindo funcionalidades para verificar disponibilidade, fazer reservas e cancelar reservas.

Sistema de Faturamento:
Implemente um sistema que gere faturas para clientes, incluindo cálculos de impostos e descontos.

Integração com Banco de Dados:
Crie um projeto que integre COBOL com um banco de dados (como DB2 ou MySQL) para armazenar e recuperar dados de forma eficiente.
